# Race mechanics and balance

This folder holds lasting, race-specific documentation covering stats, innates,
restrictions, mechanics, strengths, weaknesses, and balance rationale. Use one
Markdown file per race, such as `human.md`, with links to the relevant source and
tests. Distinguish verified behavior from balance estimates and design judgments.

- [PC racial stats](race-stats.md): racial factors, effective-stat calculations,
  gameplay consumers, resource formulas, and gearing breakpoints.
- [PC racial innates](race-innates.md): all PC racial grants and unlocks, active
  powers, passive effects, gameplay interactions, costs, and balance tradeoffs.
- [PC race tempo](race-tempo.md): racial melee and casting timing, action gates,
  attack payloads, recovery, and worked comparisons of effects and repeat rates.
- [PC race combat resolution](race-combat-resolution.md): attack and spell
  delivery, defenses, saves, control, sustain, and worked racial comparisons.
- [Miscellaneous race balance notes](race-misc.md): historical evil-race
  hardship/power rationale and Huge player races' one-hand use of two-handed weapons.
- [Race combat resolution issues](race-combat-resolution-issues.md): potential
  defects, gameplay impact, recommendations, and unresolved balance contracts.
- [Race tempo issues](race-tempo-issues.md): potential timing defects, gameplay
  impact, recommended fixes, and distinctions from intentional timing policies.
- [Race stats issues](race-stats-issues.md): potential stat-mechanics bugs,
  gameplay impact, recommended fixes, design questions, and resolved findings.
- [PC race size](race-size.md): complete race size assignments, growth and form
  changes, combat target limits, physical mass, and other gameplay effects.
- [Race size issues](race-size-issues.md): potential bugs, the six inconsistent
  racial mappings, gameplay impact, and recommended fixes.

See the [race and class configuration guide](../../content/classes_and_races.txt)
for creation tables and eligibility, and the [class overview](../CLASSES.md) for
shared class and progression rules.

Proposed changes belong in [design](../../design/); temporary investigations belong
in [ongoing projects](../../ongoing-projects/). Consolidate lasting findings here.
