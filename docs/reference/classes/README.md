# Class mechanics and balance

This folder holds lasting, class-specific documentation covering mechanics,
formulas, specializations, strengths, weaknesses, and balance rationale. Use one
Markdown file per class, such as `monk.md`, with links to the relevant source and
tests. Distinguish verified behavior from balance estimates and design judgments.

Start with the [class overview](../CLASSES.md) for shared rules and the catalogue.
The [class points proposal](../CLASS-POINTS.md) provides a balance review framework.

Proposed changes belong in [design](../../design/); temporary investigations belong
in [ongoing projects](../../ongoing-projects/). Consolidate lasting findings here.
